# Политика конфиденциальности

Приложение "TikTok Analytics Agent" — учебный проект, который получает
через TikTok Display API следующие данные авторизованного пользователя:
базовую информацию профиля, список видео и их статистику (просмотры,
лайки, комментарии, репосты).

Как используются данные:
- данные обрабатываются локально на устройстве пользователя;
- данные используются только для анализа собственного аккаунта
  (выявление лучшего времени публикации, влияния длительности видео
  и хэштегов на вовлечённость);
- данные не передаются третьим лицам, не продаются и не используются
  в рекламных целях;
- данные не хранятся на внешних серверах — только локально.

Пользователь может в любой момент отозвать доступ приложения к своему
TikTok-аккаунту через настройки TikTok: Профиль → Настройки и
конфиденциальность → Безопасность → Управление доступом к приложениям.
