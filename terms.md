# Условия использования

Это учебный проект, разработанный в рамках университетского курса.
Приложение "TikTok Analytics Agent" предназначено для личного
использования автором проекта и анализирует статистику только
собственного TikTok-аккаунта пользователя, прошедшего авторизацию.

Используя это приложение, вы соглашаетесь с тем, что:
- приложение работает в тестовом режиме (Sandbox) и не распространяется
  публично;
- доступ предоставляется только владельцу аккаунта, прошедшему
  авторизацию через TikTok Login Kit;
- данные используются исключительно в целях учебной и аналитической
  работы и не передаются третьим лицам.

Автор проекта не несёт ответственности за использование приложения
третьими лицами за пределами учебных целей.
